Ok, so this document is to explain a few things about the project, so here goes nothing 

## 1.- Why the project feels incomplete? 
I started the project thinking it would be way bigger than it ended up being, originally it had like 4 endpoints planned, but i had a change of mindset. I decided to end the project prematurely because it wasn't something 'real-life usable', sure it was useful to learn, but that's it. Besides i was planning to do not only this but other similar projects but I realized that wasn't the way to go. So instead of doing 5 lame projects I stopped and in the future (mind you i wrote this the 3/3/2026) I am planning to do one big project going deep into the tecnologies i actually want to learn.

## 2.- AI use on the project? 
Yes, I did use AI for the project, but in a smart way. I hate 'vibe coding' because i believe that's another way of AI slop, but AI is here to stay so I gotta adapt, and i do so by using a simple principle: 

**If i can't understand what the AI did in a project, I should not be using AI to do that project**

Is that simple, and that's why i used AI like three times only (as seen in the PRs history of the repo), besides that I use AI to investigate and understand documentation and tools, but decisions about architecture and so are mainly taken by me (a human).

## 3.- Possible ways to make the project better 

One of the first things to note is the fact that the project doesn't do anything with the data obtained. Originally I was planning to do other endpoint to do analysis on the data such as max prices and averages and so but well that didn't happen. 

Another thing to note is that next time i will use docstrings and typehints on functions from the beggining, as well as do the documentation from the beginning too because i realized now why is a bad idea to leave all the docs till the end (I'm writing this at 12am).

Finally there are 3 things I will use next time and that is Async, Auth management, Docker and Caching (with programs like Redis), i didn't wanted to do it now because that would add too much complexity and would be 'overengineering' the project, but i am aware i need to use those tools in a serious project.
